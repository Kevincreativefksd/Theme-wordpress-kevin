Tema WordPress klasik bergaya editorial minimalis untuk media ekonomi, bisnis, keuangan, dan investasi.

== Description ==

* Tanpa framework, tanpa jQuery, tanpa font eksternal, tanpa proses build.
* CSS dan JS total sekitar 9 KB (gzip); JS vanilla dengan defer.
* Kompatibel dengan Rank Math SEO: tema TIDAK mencetak meta description, canonical, Open Graph, Twitter Card, maupun schema.
* Mendukung Gutenberg (alignwide/alignfull, tabel, embed responsif, blockquote, daftar, galeri).
* Seluruh pengaturan ada di Appearance > Customize > Zona Ekonomi.
* Teks bawaan tema berbahasa Indonesia (siap diterjemahkan; lihat languages/zona-ekonomi.pot).

== Installation ==

1. Appearance > Themes > Add New Theme > Upload Theme, pilih zona-ekonomi-theme.zip, lalu Install Now dan Activate.
2. Buka Appearance > Customize > Zona Ekonomi untuk mengatur tema.

== Setup singkat ==

* Logo: Customize > Identitas Situs > Logo. Header berwarna hitam, gunakan logo berwarna terang/putih (PNG transparan atau SVG).
* Ikon situs (favicon): Customize > Identitas Situs > Ikon Situs.
* Menu: Customize > Menu, tetapkan lokasi "Navigasi utama", "Navigasi sekunder", dan "Navigasi footer".
* Beranda: Settings > Reading boleh memakai "Your latest posts" atau halaman statis; beranda editorial tetap tampil. Jika memakai halaman statis, pilih juga "Posts page" untuk daftar semua artikel.
* Pilihan Editor: centang "Stick to the top of the blog" pada artikel yang ingin dipilih (maksimal 3 tampil).
* Artikel populer: dihitung dari jumlah komentar (ringan, tanpa tulis ke database). Nonaktif secara default.
* Setelah mengaktifkan tema pada situs yang sudah punya artikel, jalankan plugin "Regenerate Thumbnails" sekali agar ukuran gambar baru tersedia.
